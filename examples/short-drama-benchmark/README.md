# 原创短剧：从虚拟评审到真实盲测的最小实验

**新增视觉交付：1 张实际生成的六镜关键帧拼图**，见 [视觉预览](visual-preview.html) 与 `assets/midnight-letter-keyframes.png`。原生图像生成调用 1 次，已保存真实 PNG（尺寸与 SHA256 见资产清单）。这不是影片；实际发现师傅在第2镜/第5镜胡须变化，不能宣称跨镜一致性已通过。没有模型裁判或真人评分。

**离线实验交付：3 份原创 60 秒文字分镜、HTML 阅读包、平衡顺序的待招募分配表、空真人评分表、规则敏感性报告。没有生成视频、没有调用视频模型、没有真人参与、没有观看或留存数据。**

## 运行与已验证结果

在仓库根目录：

```sh
python examples/short-drama-benchmark/run.py
python -m unittest discover -s examples/short-drama-benchmark -p 'test_*.py' -v
python -O -m unittest discover -s examples/short-drama-benchmark -p 'test_*.py' -q
```

打开 `output/storyboards.html` 阅读《午夜来信》。这是 AI 助手原创后由模板程序输出的分镜草案，**不是运行时大模型生成器，也不是已制作的 AI 电影**。三份分镜使用同一人物、地点、时长；候选加强开场线索并补足因果路径，负例故意加入道具、时段和情节断裂。每版 6 镜，60 秒仅为拟定时长，未测朗读速度。

2026-11-03 实跑：4 项测试在普通及 `-O` 模式均通过；重复构建字节哈希一致。3 种人为定义的偏好规则对候选相对基线给出 +3、+2、−2 的任意效用单位。**换一套假设就能翻转结论**；不能把这些数字归一化后当作满意度、胜率、观看率、收入或 AI 能力。负例在三套规则下均较候选低 4 单位，只是测试规则能否命中人为植入的缺陷。新增代码未改动已有交易或产品模块。

离线 `run.py` 的模型调用 0、付费 API 调用 0，未采购素材；随后另行运行原生图像生成 1 次，其计费状态未查询，不能把整个制作过程声称为零模型调用或零总费用。不代表人工、计算、后续视频生产的总成本为零。

3. [VBench 官方仓库](https://github.com/Vchitect/VBench)、[CVPR 2024 论文](https://openaccess.thecvf.com/content/CVPR2024/papers/Huang_VBench_Comprehensive_Benchmark_Suite_for_Video_Generative_Models_CVPR_2024_paper.pdf)、[Apache-2.0 许可](https://github.com/Vchitect/VBench/blob/master/LICENSE)：其 16 维度中，主体一致性、背景一致性、闪烁、运动平滑、成像质量可用于未来视频技术验收。代码许可证已查；**不推定所有视频、模型权重和依赖都可商用**。本次未复制或运行 VBench，没有 VBench 分数。

## 可执行迭代闭环

1. **冻结任务**：同一原创故事、目标人群、60 秒、竖屏/横屏、字幕语言、声音条件和预算。记录候选文件哈希、版本、模型标识、提示、种子、全部尝试和人工修改时间。现在只冻结文字分镜，不能拿它和商业视频比较。
2. **开发集找错**：脚本规则检查时长与连续性；如具备已授权的视频引擎，再生成全部预设种子，保留失败和重试成本。独立于生成器的评审模型可给出带具体镜头证据的缺陷清单，但其输出必须标记 `synthetic_model_judgment`。
3. **一次只改少数变量**：本例修改开场信息及第三镜因果提示。保存基线和候选，不只展示“最好的一条”。冻结后留出集不再用于调参；若依据留出反馈修改，旧留出变成开发集，须另建未看过的留出。
4. **虚拟受众压力测试**：替换偏好、耐心、题材厌恶、字幕依赖等假设，看结论能否翻转。当前 `simulate()` 是透明任意规则，**不是虚拟真人、更不是已校准代理**。没有人类锚点时，只能找逻辑脆弱点。
5. **获准后真人盲评**：使用匿名片段、平衡 A/B 顺序，同一设备/声音说明，不告诉作者、模型和候选身份；评分者可选平局、两者都不喜欢、退出。组织者保管 `organizer-key.json`，不要把整份输出目录交给受试者。当前 HTML 含全部分镜，适合内部预览，不是已隔离的正式盲测界面。分配表 12 个位置只是流程样例，不是招募计划或足够统计功效的保证。
6. **发布结论的门槛**：预注册主要终点、最小有用差异、招募与剔除规则、样本量依据和分析方法；收齐真人数据后报告效应和区间，同时披露退出/缺失，不能用虚拟数据填补。未授权接触真实观众，当前不招募、不发消息、不发布。

## 观看体验指标与分析计划（尚未执行）

- 主要终点建议：真实观众对成品的配对偏好，选择候选/基线/平局/都不喜欢。保留全部类别；可另报非平局胜率，但明确分母，不能偷偷删掉不喜欢者。
- 文字阶段仅评：因果可理解度、情绪共鸣、继续阅读意愿（1–5 或明确 yes/no），不把继续阅读意愿当作实际观看留存。
- 成片后才测：首次播放到 3 秒与 10 秒的存活率、观看秒数/总时长、完播率、重看率、下一集真实点击。提前固定分母（如首次有效开始播放者）、暂停/后台/重复播放处理、退出与技术故障处理。主观“愿意看”与行为分开报告。
- 技术验收：角色/道具跨镜一致性、声画同步、字幕可读性、镜头可理解度。质量分不能代替剧情吸引力。手工故意坏样本用于测试评审敏感性，不与正常候选混成营销胜率。
- 配对设计以**人**为独立统计单位，不把同一人的多个镜头评分当成独立样本。未来多故事时按人/故事聚类估计区间；独立非平局配对可报 Wilson 区间，小样本不做稳定人群推论。
- 先按主要终点决策，其余探索性标注；如多候选、多指标反复选最优，应控制多重比较并保留独立确认样本。样本量根据预期效应及所需精度设计，不由本例的 12 行模板决定。
- 模型裁判与真人一致性须在同一未训练的样本上报告，含顺序翻转稳定性、平局率、分组误差。即使相关性高，也不能推断真实留存或购买。
- 真实产品对照尚未运行。只有采用同一合法原创素材与受控预算得到实际成品并经独立真人盲测，才能提出限定于该样本/用途的比较；绝不预先承诺领先。
