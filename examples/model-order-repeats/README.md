**相同高价提示本身就产生不同选择。** 因此上一轮的展示顺序差异不能直接解释为顺序效应。本轮高价两种顺序都各有一次B和一次不买，只是描述性计数，不能说明两者等效或不存在顺序效应。低价4次A也不能证明真人购买率或稳定需求。
